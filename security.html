Reporting a security vulnerability in Meridian

Last updated: 7 October 2026

How to report

Report privately — please do not publish an exploitable problem before it is fixed. Write to isfrostly+security@gmail.com. Meridian is maintained by one developer; the address is read every working day.

Helpful in a report: what an attacker gains (the impact); the smallest reproduction and the Meridian version it was seen on (Settings → About); whether it needs local network access, physical access or a paired phone; and whether you believe it is being exploited — if so, say it in the first line.

Reports in any language are fine; English or German get the fastest reply.

What to expect

  • Acknowledgement that a person has read it: within 5 working days.
  • Initial assessment (reproduced or not, severity, likely direction): within 15 working days.
  • Fix for a confirmed high-severity issue: as fast as possible, with a target date agreed with you.
  • Lower-severity issues: fixed in a normal release.
  • Public disclosure: coordinated with you, after a fix is available.

If a deadline is going to slip, you are told before it does.

Coordinated disclosure

  • Please allow time for a fix before publishing details: 90 days from acknowledgement by default, shorter for something already exploited, longer if the fix depends on an upstream component (for example Android System WebView).
  • Credit is given by default; say if you would rather not be named.
  • There is no bug bounty.
  • Only test on devices and networks that are yours.

Supported versions

Security fixes are made for the current version on Google Play. Web content is rendered by Android System WebView, which Google updates separately.

Sicherheitslücken in Meridian melden

Stand: 7. Oktober 2026

So meldest du

Bitte vertraulich melden und eine ausnutzbare Lücke nicht veröffentlichen, bevor sie behoben ist. Schreib an isfrostly+security@gmail.com. Meridian wird von einem Entwickler betreut; die Adresse wird an jedem Werktag gelesen.

Hilfreich: was ein Angreifer gewinnt (die Auswirkung); die kleinste Reproduktion und die Meridian-Version (Einstellungen → Über); ob lokaler Netzwerkzugang, physischer Zugang oder ein gekoppeltes Handy nötig ist; und ob du glaubst, dass die Lücke ausgenutzt wird — dann bitte in der ersten Zeile.

Meldungen in jeder Sprache sind willkommen; auf Englisch oder Deutsch antworte ich am schnellsten.

Was du erwarten kannst

  • Bestätigung, dass ein Mensch die Meldung gelesen hat: innerhalb von 5 Werktagen.
  • Erste Einschätzung (reproduziert oder nicht, Schweregrad, Richtung): innerhalb von 15 Werktagen.
  • Behebung einer bestätigten schweren Lücke: so schnell wie möglich, mit einem mit dir abgestimmten Zieltermin.
  • Weniger schwere Lücken: in einem normalen Release.
  • Veröffentlichung: mit dir abgestimmt, nachdem eine Behebung verfügbar ist.

Wenn sich eine Frist verschiebt, erfährst du es vorher.

Koordinierte Offenlegung

  • Bitte lass Zeit für eine Behebung, bevor du Details veröffentlichst: standardmäßig 90 Tage ab Bestätigung, kürzer bei bereits ausgenutzten Lücken, länger, wenn die Behebung von einer Fremdkomponente abhängt (etwa Android System WebView).
  • Du wirst standardmäßig genannt; sag Bescheid, wenn du das nicht möchtest.
  • Es gibt keine Bug-Bounty.
  • Teste nur auf Geräten und in Netzwerken, die dir gehören.

Unterstützte Versionen

Sicherheitskorrekturen gibt es für die aktuelle Version bei Google Play. Webinhalte stellt Android System WebView dar, das Google separat aktualisiert.
